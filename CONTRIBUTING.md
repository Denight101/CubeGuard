# Contributing

Read LICENSE before using or contributing. This project permits personal, noncommercial use and noncommercial source redistribution; it is not permissively licensed open source. Contributions must be your own work or properly authorized and must be offered under the repository's license. Do not submit third-party code whose license is incompatible with these terms.

Useful contributions include local reproducible bug reports, bypass tests, documentation corrections, performance measurements and a simulated per-device command gateway. Keep claims tied to implemented behavior. Do not describe the existing prototype as quantum protection, a complete endpoint firewall or an industrial safety device.

Run `node --test test.js`. Tests must use local test servers or simulations and must not change system firewall rules. Explain the concrete problem, the resulting behavior and the validation in pull requests. For vulnerabilities, follow SECURITY.md rather than publishing sensitive details in an issue.
